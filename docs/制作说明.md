# 海报制作说明

## 内容来源

原始资料为 [西安旅游攻略 PDF](../guide/xian-travel-guide.pdf)。每日行程主要依据第 4、5、6 页，路线概览与预约提醒参考第 2、3、11 页。

第三天保留原攻略对早场与约 16:00 入馆的不同建议，丽山园和华清宫游览明确为可选。第四天以五个独立方案呈现，避免把备选玩法误串成一天的固定路线。

## 视觉形式

四张海报使用同一套竖版视觉：毛笔字大标题、奶油色纸张背景、深绿与橙色标签、上方插画路线、左侧行程安排、右侧景点拼贴、底部实用提醒。第四天将时间轴改为五种玩法卡片。

生成方式为订阅内置 Image 2，每张输出为 941 × 1672 像素 PNG。四张均已查看生成画面，并核对主要地点、时间条件、票价、路线顺序及可选关系。

第一张以用户上传的一日行程海报作为视觉参考；第二至四张另引用第一张成品保持系列风格。提示词描述中的高分辨率是生成目标，实际交付分辨率以上述 PNG 文件为准。仓库不附上传的参考海报。

海报中的景点画面为生成式插画与仿实景拼贴，不能当作景点实拍；票价、规则、交通和场次未经本次实时核验，以出发前官方信息为准。
